# Raccourcis clavier

Voici les touches par défaut. Vous pouvez changer les touches du mod dans les réglages des
commandes du jeu, où leurs noms commencent par « Tilt Shift : ».

## Partout dans le jeu

| Touche | Action |
| --- | --- |
| **Ctrl droit + K** | Ouvrir ou fermer le panneau |
| **Ctrl droit + J** | Activer ou désactiver tous les effets (vos réglages sont conservés, enregistrés ou non) |
| **Ctrl droit + 1** à **9** | Appliquer le profil enregistré de ce numéro et activer les effets ; le même chiffre à nouveau les désactive |
| **Ctrl droit + N** | Ajouter une caméra fixe à la vue actuelle |
| **Ctrl droit + C** | Caméra fixe activée ou désactivée (retour à la vue en direct) |
| **Ctrl droit + V** | Caméra fixe suivante |
| **Ctrl droit + T** | Lancer la timeline caméra ; appuyer de nouveau pour revenir |

Les touches des caméras fixes et de la timeline ne fonctionnent qu'une fois ces extras
activés dans le panneau. Avant cela, un appui affiche seulement un court message qui le
signale. La ligne Rendu du panneau indique quel profil porte quel numéro ; voir
[Rendus et profils](looks-and-profiles.md#raccourcis-clavier).

## Dans le panneau

| Touche | Action |
| --- | --- |
| Flèches **Haut / Bas**, ou pavé numérique **8 / 2** | Sélectionner une ligne |
| Flèches **Gauche / Droite**, ou pavé numérique **4 / 6** | Modifier la valeur |
| **Page préc. / Page suiv.**, ou pavé numérique **7 / 9** | Modifier la valeur par grands pas |
| **Entrée**, **Espace** ou pavé numérique **5** | Plier une section, exécuter une action, basculer un interrupteur ou remettre une valeur par défaut |
| **Échap** | Fermer le panneau |
| **Croix directionnelle** de la manette | Sélectionner et modifier |

Pour la souris, voir [Le panneau](panel.md#souris).

## Vol libre d'une caméra

| Touche | Action |
| --- | --- |
| **Z Q S D** (vos touches de déplacement) | Déplacer la caméra |
| Souris | Orienter la caméra |
| **Maj** | Aller plus vite |
| **Entrée** | Enregistrer la nouvelle position |
| **Échap** | Annuler et remettre la caméra en place |

## Pendant la lecture de la timeline

| Touche | Action |
| --- | --- |
| **Échap** ou **Ctrl droit + T** | Arrêter et revenir |
