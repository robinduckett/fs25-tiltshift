# Raccourcis clavier

Voici les touches par défaut. Vous pouvez modifier les touches du mod dans les réglages des
commandes du jeu ; leurs noms commencent par « Tilt Shift : ».

## Partout dans le jeu

| Touche | Action |
| --- | --- |
| **Ctrl droit + K** | Ouvrir ou fermer le panneau |
| **Ctrl droit + J** | Tous les effets activés ou désactivés (vos réglages sont conservés, même non enregistrés) |
| **Ctrl droit + 1** à **9** | Appliquer le profil enregistré qui porte ce numéro et activer les effets ; le même chiffre à nouveau les désactive |
| **Ctrl droit + N** | Ajouter une caméra fixe à la vue actuelle |
| **Ctrl droit + C** | Caméra fixe activée ou désactivée (retour à la vue directe) |
| **Ctrl droit + V** | Caméra fixe suivante |
| **Ctrl droit + T** | Lancer la timeline caméra ; à nouveau pour revenir |

Les touches des caméras fixes et de la timeline fonctionnent une fois ces extras activés dans
le panneau. Avant cela, elles affichent un court message pour le signaler. Le numéro de
chaque profil s'affiche dans la ligne Rendu du panneau ; voir
[Rendus et profils](looks-and-profiles.md#raccourcis-clavier).

## Dans le panneau

| Touche | Action |
| --- | --- |
| Flèches **Haut / Bas** ou pavé numérique **8 / 2** | Choisir une ligne |
| Flèches **Gauche / Droite** ou pavé numérique **4 / 6** | Modifier la valeur |
| **Page préc. / Page suiv.** ou pavé numérique **7 / 9** | Modifier la valeur par grands pas |
| **Entrée** ou **Espace** ou pavé numérique **5** | Plier / déplier une section, exécuter une action, basculer un interrupteur ou remettre une valeur par défaut |
| **Échap** | Fermer le panneau |
| **Croix directionnelle** de la manette | Choisir et modifier |

La souris est décrite dans [Le panneau](panel.md#souris).

## Vol libre d'une caméra

| Touche | Action |
| --- | --- |
| Vos **touches de déplacement** (Z Q S D ou W A S D) | Déplacer la caméra |
| Souris | Orienter la caméra |
| **Maj** | Aller vite |
| **Entrée** | Enregistrer la nouvelle position |
| **Échap** | Annuler et remettre la caméra en place |

## Pendant la timeline

| Touche | Action |
| --- | --- |
| **Échap** ou **Ctrl droit + T** | Arrêter et revenir |
