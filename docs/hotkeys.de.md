# Tastenkombinationen

Das sind die Standardtasten. Die Tasten der Mod kannst du in den Steuerungseinstellungen
des Spiels ändern; ihre Namen beginnen dort mit „Tilt Shift:“.

## Überall im Spiel

| Taste | Funktion |
| --- | --- |
| **Rechts-Strg + K** | Panel öffnen oder schließen |
| **Rechts-Strg + J** | Alle Effekte ein oder aus (deine Einstellungen bleiben erhalten, gespeichert oder nicht) |
| **Rechts-Strg + 1** bis **9** | Das gespeicherte Profil mit dieser Nummer anwenden und die Effekte einschalten; dieselbe Zahl noch einmal schaltet sie aus |
| **Rechts-Strg + N** | Statische Kamera an der aktuellen Ansicht hinzufügen |
| **Rechts-Strg + C** | Statische Kamera ein oder aus (zurück zur Live-Ansicht) |
| **Rechts-Strg + V** | Nächste statische Kamera |
| **Rechts-Strg + T** | Kamera-Zeitleiste starten; noch einmal drücken, um zurückzukehren |

Die Tasten für statische Kameras und die Zeitleiste funktionieren erst, wenn diese Extras
im Panel eingeschaltet sind. Vorher zeigt ein Druck darauf nur eine kurze Meldung dazu.
Welches Profil welche Nummer hat, siehst du in der Look-Zeile des Panels; siehe
[Looks und Profile](looks-and-profiles.md#tastenkombinationen).

## Im Panel

| Taste | Funktion |
| --- | --- |
| Pfeiltasten **Hoch / Runter** oder Ziffernblock **8 / 2** | Zeile wählen |
| Pfeiltasten **Links / Rechts** oder Ziffernblock **4 / 6** | Wert ändern |
| **Bild-auf / Bild-ab** oder Ziffernblock **7 / 9** | Wert in großen Schritten ändern |
| **Enter**, **Leertaste** oder Ziffernblock **5** | Abschnitt ein- oder ausklappen, Aktion ausführen, Schalter umlegen oder Wert auf den Standard zurücksetzen |
| **Esc** | Panel schließen |
| Gamepad **Steuerkreuz** | Wählen und ändern |

Zur Maus siehe [Das Panel](panel.md#maus).

## Eine Kamera fliegen

| Taste | Funktion |
| --- | --- |
| **W A S D** (deine Bewegungstasten) | Kamera bewegen |
| Maus | Kamera drehen |
| **Umschalt** | Schneller bewegen |
| **Enter** | Neue Position speichern |
| **Esc** | Abbrechen und die Kamera zurücksetzen |

## Während die Zeitleiste läuft

| Taste | Funktion |
| --- | --- |
| **Esc** oder **Rechts-Strg + T** | Anhalten und zurückkehren |
