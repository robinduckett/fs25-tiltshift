# Tastenkombinationen

Das sind die Standardtasten. Die eigenen Tasten der Mod kannst du in den
Steuerungseinstellungen des Spiels ändern; ihre Namen beginnen mit „Tilt Shift:“.

## Überall im Spiel

| Taste | Funktion |
| --- | --- |
| **Rechts-Strg + K** | Panel öffnen oder schließen |
| **Rechts-Strg + J** | Alle Effekte ein oder aus (deine Einstellungen bleiben erhalten, auch ungespeicherte) |
| **Rechts-Strg + 1** bis **9** | Das gespeicherte Profil mit dieser Nummer anwenden und Effekte einschalten; dieselbe Zahl erneut schaltet sie aus |
| **Rechts-Strg + N** | Statische Kamera an der aktuellen Ansicht hinzufügen |
| **Rechts-Strg + C** | Statische Kamera ein oder aus (zurück zur Live-Ansicht) |
| **Rechts-Strg + V** | Nächste statische Kamera |
| **Rechts-Strg + T** | Kamera-Zeitleiste starten; erneut, um zurückzukehren |

Die Tasten für statische Kameras und Zeitleiste funktionieren, sobald diese Extras im Panel
eingeschaltet sind. Bis dahin zeigen sie eine kurze Meldung dazu. Welches Profil welche
Nummer hat, zeigt die Look-Zeile im Panel; siehe [Looks und Profile](looks-and-profiles.md#tastenkombinationen).

## Im Panel

| Taste | Funktion |
| --- | --- |
| Pfeiltasten **Hoch / Runter** oder Ziffernblock **8 / 2** | Zeile wählen |
| Pfeiltasten **Links / Rechts** oder Ziffernblock **4 / 6** | Wert ändern |
| **Bild-auf / Bild-ab** oder Ziffernblock **7 / 9** | Wert in großen Schritten ändern |
| **Enter** oder **Leertaste** oder Ziffernblock **5** | Abschnitt ein- / ausklappen, Aktion ausführen, Schalter umlegen oder Wert auf den Standard zurücksetzen |
| **Esc** | Panel schließen |
| Gamepad-**Steuerkreuz** | Wählen und ändern |

Die Maus ist unter [Das Panel](panel.md#maus) beschrieben.

## Eine Kamera fliegen

| Taste | Funktion |
| --- | --- |
| **W A S D** (deine Bewegungstasten) | Kamera bewegen |
| Maus | Kamera drehen |
| **Umschalt** | Schnell bewegen |
| **Enter** | Neue Position speichern |
| **Esc** | Abbrechen und Kamera zurückstellen |

## Während der Zeitleiste

| Taste | Funktion |
| --- | --- |
| **Esc** oder **Rechts-Strg + T** | Stoppen und zurückkehren |
