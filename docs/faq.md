# Limitations and FAQ

## Known limitations

Weather effects are simulated
:   The game's own rain is not part of the picture the effect works on, so the mod draws its
    own rain, snow and hail. They are as close to the game's as I can get them, but they are
    not the same.

Some transparent materials disappear
:   Some decals, glass and other transparent materials are not visible while the effects are
    on. The effects work on a copy of the picture that the game makes before it draws
    transparent materials.

Preview windows show the plain world
:   The tilt-shift look, the distance blur and the weather effects appear on the main view only,
    not in the preview windows or the timeline monitor.

Third person only
:   The effect applies to orbit cameras. Cab views, first person and fixed vehicle cameras
    stay untouched.

## FAQ

I installed the mod, but nothing changes.
:   The effects start off every time you load a game. Press **Right Ctrl + J**, and make sure
    you are in a third-person view.

Where are the static cameras?
:   They are off until you switch them on: open the panel, and set **Static Cameras** in the
    EXTRAS rows to ON. Preview windows and the camera timeline appear the same way, one
    after the other.

Why did my first-person view switch to third person?
:   While a static camera is on screen, the game puts you in third person on foot so that you
    stay visible in the shot. Go back to the live view with **Right Ctrl + C**.

The game's camera key (C) does nothing.
:   It is taken over while a static camera is on screen, so it cannot pull you out of the
    shot. Go back to the live view with **Right Ctrl + C**.

I can't drive while the panel is open.
:   Your keys drive the panel while it is open. Close it with **Esc** or **Right Ctrl + K**.

How do I go back to the game's normal look?
:   **Right Ctrl + J** turns all effects off without losing anything. **Reset All Effects** in
    the panel switches every effect off and puts the game's own look back.

I changed some settings and pressed a profile key. Are my changes gone?
:   Yes, unless you saved them first: the **Right Ctrl + 1** to **9** keys apply the profile
    straight away. In the panel's **Look** row you are asked before unsaved changes are
    discarded. See [Looks and profiles](looks-and-profiles.md).

Does it work in multiplayer?
:   Yes. Everything is local to your own screen, and each player keeps their own cameras and
    timeline.
