# Tilt Shift Camera docs

The player guide for the Tilt Shift Camera mod for Farming Simulator 25, published at
<https://robinduckett.github.io/fs25-tiltshift/>.

Pages are Markdown in `docs/`, one file per language: `page.md` (English), `page.de.md`
(German), `page.fr.md` (French). The site is built with MkDocs Material and deployed to
GitHub Pages by `.github/workflows/pages.yml` on every push to `main`.

Preview locally:

```sh
pip install -r requirements.txt
mkdocs serve
```
